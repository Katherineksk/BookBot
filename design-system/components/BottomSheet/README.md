Нижняя шторка: добавление книги (способы, поиск, ручной ввод) и отметка чтения за сегодня.

**Что даёт потребитель:** заголовок `sheet-title` и содержимое: строки способов, поле поиска, поля формы или шагатель страниц/минут.

**Сборка:** `surface`, `radius-sheet` сверху, отступы 14px сверху, `space-5` по бокам, 28px снизу плюс безопасная зона; «ручка» 36×5px `line` по центру; под ней `scrim` на весь экран, нажатие по нему закрывает шторку. Строки способов: плитка 38px (`field`, `radius-sm`), подпись `body`, пояснение `caption` цветом `ink-secondary`, разделитель `line`. Появление пружиной 0.45s `cubic-bezier(0.34, 1.35, 0.64, 1)`.

**Нельзя:** вкладывать шторку в шторку; больше одной шторки на экране.
