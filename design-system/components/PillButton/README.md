Чёрная пилюля: главное действие блока («Читал(а) сегодня», «Попробовать»), и мини-кнопка «Добавить».

**Что даёт потребитель:** короткий глагол. Одна пилюля на блок; вторичное действие оформляй ссылкой `accent-blue` или текстом `ink-secondary`, не второй пилюлей.

**Сборка:** пилюля `ink` на `on-ink`, `radius-pill`, `size-pill-w` × `size-pill-h`, стиль `button`; на пустом состоянии ширина по тексту с отступом 26px по бокам. Мини-кнопка в строке результата: `accent-blue`, белый текст, `radius-sm`, отступ 6px × 12px, стиль `button`.

**Состояния:** нажатие затемняет на 15%; недоступная кнопка 40% непрозрачности. Фокус: обводка 2px `accent-blue` с зазором 2px.
