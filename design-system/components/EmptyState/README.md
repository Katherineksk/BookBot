Пустое состояние главной: полка с тремя пустыми местами, заголовок, пояснение и кнопка добавления.

**Что даёт потребитель:** действие «Добавить книгу» (открывает шторку) и, второстепенно, «Найти по названию» (открывает поиск).

**Сборка:** полка `WoodShelf` с тремя «призрачными» книгами `size-cover-shelf-w` × `size-cover-shelf-h`: пунктир 2px `ink` 22%, заливка `surface` 55%. Первая книга с «+» и пунктиром `ink` и белой заливкой; нажатие открывает шторку. Ниже, по центру: `display-cta` «Здесь пока пусто», `subtitle` (до 280px), пилюля «Добавить книгу», под ней ссылка `ink-secondary`.

**Нельзя:** иллюстраций из `Illustrations` в пустом состоянии; текста длиннее двух строк.
