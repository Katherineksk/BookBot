Плавающий таб-бар из двух вкладок (главная, библиотека) и отдельная кнопка «+» справа.

**Что даёт потребитель:** какая вкладка активна. Статистика — не вкладка: она открывается по счётчику серии на главной.

**Сборка:** строка высотой `size-tabbar` на `space-5` от краёв и низа экрана; бар (`glass`, blur 24px, `radius-tab`, `shadow-glass`) и круглая кнопка 64px с «+» через `space-2`. Активная вкладка: капсула `ink` 8% и иконка `accent-active`; неактивная иконка серая `ink-secondary`. Иконки 26px; «+» 20px, обводка 2.4px `ink`.

**Нельзя:** подписи под иконками; больше двух вкладок; стекло на любых других элементах.
