Белая карточка полки «Хочу прочитать»: заголовок и три обложки, одна крупная и две маленькие в колонке.

**Что даёт потребитель:** заголовок секции (`heading`, слева) и до трёх книг: первая в крупной колонке, две следующие в маленькой.

**Сборка:** фон `surface`, `radius-card`, `shadow-card`, внутренний отступ `space-5`, ширина 322px. Заголовок, через `space-3` содержимое: крупная обложка `size-cover-card-w` (259px высотой) и колонка маленьких `size-cover-card-sm-w` (122px высотой) с зазором `space-2`; расстояние между колонками `space-4`. Несколько карточек идут в горизонтальной прокрутке с зазором `space-5`.

**Нельзя:** вкладывать карточку в карточку; делать рамку; ставить кнопки внутрь.
