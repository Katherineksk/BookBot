Выбор статуса книги: четыре сегмента «Хочу прочитать», «Читаю», «Прочитано», «Брошено».

**Что даёт потребитель:** текущий статус; выбранный сегмент меняет книгу сразу, без подтверждения.

**Сборка:** ряд кнопок с зазором 6px, `radius-sm`, высота 36px, стиль `button` (12.5px допустимо в тесном ряду); неактивный `field` с `ink-secondary`, граница `line`; активный `ink` на `on-ink`. Цвет статуса (`neutral`, `accent-blue`, `success`, `danger`) показывай только маркером-точкой 8px перед словом в списках, не заливкой сегмента.

**Нельзя:** переносить подписи на две строки; скрывать подписи, оставляя цвет.
