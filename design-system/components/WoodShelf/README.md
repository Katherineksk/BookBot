Деревянная полка с книгами: передняя кромка и верхняя грань из `assets/Shelf/plank.png`, книги стоят на грани.

**Что даёт потребитель:** ряд `BookCover` (на полке «Далее») или корешки шириной 16–24px (на «Ваша полка»). Заголовок секции `heading` по центру над полкой на `space-7`.

**Сборка:** контейнер с нижним отступом 11px (высота кромки); кромка 11px с `shadow-shelf` и `radius-shelf`, поверх книг; верхняя грань 13px под книгами, светлее на 18%, обрезана трапецией. Книги выравнивай по нижнему краю, зазор `space-6` (22px) для обложек и 2px для корешков. Полка шире экрана не бывает: боковой отступ 6px от краёв.

**Нельзя:** рисовать дерево градиентом, если доступен plank.png; ставить на полку больше одного ряда.
