# Раскладка и отступы

Мобильный экран 393pt шириной; боковое поле `space-4` (16px). Все значения из макета Shelf Wireframes (iPhone 16, фрейм «Home»), если не сказано иначе.

## Главная сверху вниз

| Блок | Высота | Отступ сверху | Правило |
|---|---|---|---|
| Заголовок экрана | 41px (`title-large`) | `space-9` (70px) от верха | Слева на `space-4`, справа счётчик серии с пламенем |
| Герой: читаемая книга | 167px | 14px под заголовком | Стопка обложек слева (126px, x=32), справа название `heading`, «Читаю • %» `subtitle` и пилюля через `space-4` |
| «Далее» | 28px заголовок + полка 156px | `space-8` (44px) | Заголовок по центру, под ним `space-7` (26px) до ряда книг; книги `size-cover-shelf-w` × `size-cover-shelf-h`, зазор `space-6` |
| «Хочу прочитать» | карточка 350px | `space-8` | Белая карточка 322px, внутренний отступ `space-5`, зазор между карточками `space-5`, прокрутка по горизонтали |
| «Ваша полка» | 28px заголовок + полка 156px | `space-8` | Корешки шириной 16–24px, высотой 110–144px, зазор 2px, по центру на полке |
| Призыв «Не знаешь, что читать дальше?» | ~56px текст + пилюля | `space-8` | `display-cta`, под ним `subtitle` (4px), пилюля через `space-4`, ниже иллюстрация 245px |
| Таб-бар | 64px | плавает | Отступ от краёв и низа `space-5`, зазор до кнопки «+» `space-2` |

В карточке «Хочу прочитать»: заголовок `heading`, через `space-3` содержимое: большая обложка (`size-cover-card-w`, 259px высотой) и колонка из двух маленьких (`size-cover-card-sm-w`, 122px высотой) через `space-2`.

## Правила

- Один экран прокручивается как целое; таб-бар и «+» зафиксированы снизу, контенту снизу нужен запас 140px.
- Между секциями всегда `space-8`; между заголовком и содержимым `space-7` (над полкой) или `space-3` (в карточке).
- Заголовки над полкой по центру, заголовки внутри белых карточек слева.
- Не складывай два отступа подряд: между блоками один зазор из токенов.
- Безопасные зоны: верхний отступ экрана уже включает статус-бар; низ таб-бара добавляй безопасную зону устройства.
