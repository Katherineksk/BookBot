# Shelf — трекер книг для Telegram

Мини-приложение Telegram: библиотека на деревянной полке, серия чтения, статистика.

- `index.html`, `assets/` — Telegram Mini App (публикуется на GitHub Pages из корня ветки `main`)
- `TELEGRAM.md` — что изменено для Telegram и как подключить бота
- `prototype/` — исходный прототип из claude.ai
- `design-system/` — токены, правила, компоненты
- `canvas-prototype-old/` — ранний кликабельный макет (4 экрана из 10)
