# Shelf в Telegram: шаг 1

Корень репозитория — версия прототипа для Telegram Mini App. Исходник лежит в `prototype/` и не менялся.

## Что изменилось по сравнению с prototype/
- Подключён `telegram-web-app.js`: приложение сообщает Telegram, что готово, разворачивается на весь экран, красит шапку и низ в цвет фона, отключает закрытие свайпом вниз (чтобы не мешало прокрутке и шторке).
- Кнопка «Назад» Telegram: работает в карточке книги, внутри папки библиотеки и в шторке добавления. Свои кнопки «‹ Назад» в Telegram скрыты. Из карточки книги «Назад» теперь возвращает туда, откуда её открыли (раньше всегда на Главную).
- Данные хранятся на устройстве (localStorage), отдельно для каждого пользователя Telegram. Внутри claude.ai по-прежнему используется хранилище артефакта. Это временно, до Supabase (шаг 2).
- Таб-бар, шторка и низ экрана учитывают безопасную зону телефона.
- Исправлено: отметка чтения после полуночи записывалась на вчерашний день (дата считалась по UTC, теперь по местному времени).
- Лёгкая вибрация при добавлении книги.

## Чего пока нет
- Поиск книг: в Telegram он недоступен (работал через Claude). Будет на шаге 3 через Google Books.
- Синхронизация между устройствами: появится с Supabase.

## Как запустить в Telegram
1. **Хостинг.** Mini App открывается по публичной ссылке https. Проще всего GitHub Pages: в настройках репозитория Pages включить публикацию из ветки `main`, папка `/ (root)`. Ссылка: `https://katherineksk.github.io/BookBot/`.
2. **Бот.** В Telegram открыть @BotFather → `/newbot` → придумать имя и username.
3. **Кнопка запуска.** В @BotFather: `/mybots` → бот → Bot Settings → Menu Button → вставить ссылку из шага 1. Либо `/newapp`, чтобы приложение открывалось по ссылке `t.me/<бот>/<app>`.
4. Открыть бота и нажать кнопку меню.
